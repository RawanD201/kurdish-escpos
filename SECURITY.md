# Security Policy

## Supported versions

Security fixes are released for the latest version.

| Version | Supported |
|---------|-----------|
| 0.2.x   | Yes       |
| 0.1.x   | No        |

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/RawanD201/kurdish-escpos/security/advisories/new).
Include a description of the issue, the steps to reproduce it, and the
affected versions.

You can expect an acknowledgement within seven days. Once the issue is
confirmed, a fix will be prepared and released as soon as possible, and you
will be credited in the release notes unless you prefer otherwise.

## Scope

The package parses font files and receipt data, and opens network
connections to printers. Reports concerning malformed font files, untrusted
receipt input, or printer connections are within scope.
